# Ledger: money tracker

A private, installable money-tracking app for Android phones and Windows computers. The app stores your accounts and transactions in the browser on your device; it does not send them to a server.

## Open the live app

After GitHub Pages is enabled for this repository, open:

<https://sashakop750.github.io/Money-Tracking/>

## Install it

- **Android:** Open the live app in Chrome. Use the browser menu and choose **Install app** or **Add to Home screen**.
- **Windows:** Open the live app in Microsoft Edge or Chrome. Use the install button in the address bar, or the browser menu's **Install this site as an app** option.

The app also works offline after its first successful load. Install options depend on browser support.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)` folder, then save. GitHub Pages will publish the app at the URL above.

## Your data and backups

Data is saved in this browser on this device. It is not automatically synced between devices. Use **Manage → Data → Backup and restore** in the app to copy a backup and restore it elsewhere. Clearing this browser's site data may erase the app data.

## Project files

- `index.html` — app entry point
- `manifest.webmanifest` — installable app metadata
- `service-worker.js` — offline app-shell cache
- `icon.svg`, `icon-192.png`, and `icon-512.png` — app icons
- `Ledger_ money tracker.html` and `Ledger_ money tracker.md` — original project files
